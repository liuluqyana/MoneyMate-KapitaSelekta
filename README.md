# MoneyMate

**Manage Your Money, Build Your Future.**

MoneyMate adalah aplikasi web pengelola keuangan pribadi. Pengguna dapat mencatat pemasukan dan pengeluaran, memantau anggaran bulanan, menetapkan target tabungan, dan melihat analisis keuangan melalui grafik. Seluruh aplikasi berjalan langsung di browser tanpa backend.

## Fitur

- **Dashboard**: ringkasan saldo, pemasukan, pengeluaran, dan sisa anggaran, lengkap dengan grafik dan transaksi terbaru.
- **Manajemen Transaksi**: tambah, ubah, dan hapus transaksi. Tersedia pencarian, filter jenis/kategori/bulan, pengurutan, dan pagination.
- **Analisis Keuangan**: tren pemasukan dan pengeluaran, distribusi pengeluaran per kategori, perbandingan bulanan, dan insight otomatis.
- **Anggaran Bulanan**: atur batas pengeluaran total maupun per kategori, dengan indikator status warna dan progress bar.
- **Target Tabungan**: buat tujuan menabung, pantau progresnya, dan perbarui jumlah yang terkumpul.
- **Pengaturan dan Data**: ubah nama dan saldo awal, ekspor ke CSV atau JSON, impor dari JSON, dan reset data.
- **Responsif**: tampilan menyesuaikan layar desktop maupun HP.

## Teknologi

- HTML, CSS, dan JavaScript (vanilla)
- Tailwind CSS
- Chart.js
- Font Plus Jakarta Sans
- localStorage untuk penyimpanan data
